# 0.2.3-beta · Initial public beta

Fingertip Incantations provides configurable HUD slots for inventory items, keybinds, and supported mod skills, with Mixed/Fingertip hotbar modes and a customizable radial menu.

This release includes three visual themes, layout editing, matching-stack supply continuation, skill-state displays, detailed hover information, and built-in Iron's Spells 'n Spellbooks integration.

## Requirements

- Minecraft Java Edition 1.21.1
- NeoForge 21.1.181 or later for Minecraft 1.21.1
- Install on both the client and server for multiplayer
- Optional Iron's Spells integration: 1.21.1-3.15.5 or later

## Before playing

Open the inventory and click the Fingertip logo to configure your layout. Review the Key takeover page if you want another mod to retain its original shortcuts.

# 0.2.3-beta · 首次公开测试版

指尖咒文提供可配置的物品、按键与技能 HUD 格子，支持混合／指尖两种快捷栏模式和可配置轮盘。

本版包含三套主题、布局编辑、同类补给接续、技能状态显示、详细悬停说明和内置 Iron's Spells 'n Spellbooks 适配。

需要 Minecraft Java 版 1.21.1、对应的 NeoForge 21.1.181 或更新版本。多人游戏需客户端和服务端均安装。Iron's Spells 为可选联动，支持 1.21.1-3.15.5 及以上。

打开背包，点击指尖 Logo 配置布局；需要保留其他模组原快捷键时，请在「按键接管」页放行对应模组。

源码采用 MIT；Logo 与美术素材按独立声明保留所有权利。
